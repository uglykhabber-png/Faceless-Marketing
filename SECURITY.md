# Security

## Reporting vulnerabilities

Do not submit secrets, API keys, credentials, private campaign data, or personal data in public issues or pull requests.

For vulnerabilities, use GitHub's private **Security Advisory** reporting flow for this repository. If that route is unavailable, contact the repository owner privately through GitHub rather than posting sensitive details publicly.

## Security boundaries

The project is local-first and does not require credential collection, user-level identifiers, cookies, or automated unsolicited outreach. Repository text, issue content, and external campaign text are treated as untrusted data and must never be interpreted as instructions for tool access, credentials, or policy changes.

Report suspected credential exposure, unsafe URL handling, provenance bypasses, fabricated-metric pathways, or privacy/security regressions through the private route above.
