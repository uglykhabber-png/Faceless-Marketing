# Roadmap

## Current line — v0.2

Complete the evidence-first foundation: repository audit, deterministic campaign/evidence models, discoverability analysis, decision policy, machine-readable reporting, and governance gates.

## Next — v0.3

Harden the campaign ledger as the canonical local data store, including explicit Asset, Publication, MetricObservation and Evidence relationships, migration-safe schema versions, and stronger round-trip/adversarial coverage.

## v0.4

Build the evidence engine: provenance graph, freshness/staleness checks, contradiction detection, observation/derivation boundaries, and benchmark snapshots.

## v0.5

Expand content/discoverability intelligence across README, docs, metadata, repository structure and contributor onboarding friction.

## v0.6

Add a deterministic decision engine with versioned scoring policy, opportunity states, experiments, effort/risk estimates and explainable prioritization.

## v0.7

Add reporting adapters for JSON, CSV, SARIF, Markdown and eventually HTML, with stable public schemas.

## v0.8

Add broader adversarial corpus, policy enforcement, provenance validation, regression fixtures and release certification.

## v1.0

Integrate the layers into a cohesive OSS Growth Intelligence Platform while keeping AI/provider integrations optional and unable to bypass evidence, security or governance controls.
